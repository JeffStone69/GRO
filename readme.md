# GROW (xforge-trader packaging)

This repo contains the packaged/distributable form of the XForge Trader system (v9.2.0).

**Note:** This is largely historical. Active development is in the [Hermes](https://github.com/JeffStone69/Hermes) repository.

## Key Files
- `pyproject.toml` — Packaging config
- `launch.command` — macOS launcher

See the main Hermes/xforge-trader for current code.
