# 🚀 xForgeTrader v8

**The only trading app that gets smarter the more it fails.**

A self-improving, Grok-powered profit recommendation engine that runs beautifully in your browser — even when the markets (or your Wi-Fi) refuse to cooperate.

---

### ✨ What It Actually Does
- Scans tickers with RSI, ATR, moving averages and a dash of simulated ML magic
- Backtests strategies and runs walk-forward analysis
- Connects to Interactive Brokers (data only, no accidental yacht purchases… yet)
- Pulls live data via Alpha Vantage when yfinance throws a tantrum
- Lets Grok write your trade plans while you sip coffee
- Logs every error, then politely asks Grok to fix them
- Includes a one-click “Exit & Close Terminal” button (because we’re thoughtful like that)

Demo mode always works. Real data is optional. Self-improvement is mandatory.

---

### 🏃‍♂️ Quick Start (macOS)
1. Double-click `Run-xForgeTrader.command`
2. Watch the glorious splash screen appear
3. Enter your `xai-` API key in the **Grok Trade Planner** tab (optional but highly recommended)
4. Click **Scan & Recommend** and enjoy the show

(Windows & Linux users: run `python3 xforge_trader.py` after creating a venv and installing `requirements.txt`.)
